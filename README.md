# ZyeemZia™ Academy

The home of every ZyeemZia™ course: [academy.zyeemzia.com](https://academy.zyeemzia.com/)

An open campus for learners everywhere: 15 certification tracks in networking, cybersecurity, AI, leadership and IT service management, plus Quran & Arabic, French, Bangla and Mandarin courses. All free.

## What is on the page

- **Route map**: every course placed by subject and level, like a transit map.
- **Learning routes**: five routes from beginner to master level.
- **Course catalogue**: search and filter all courses, with details, books and PDFs.
- **Where to start**: two questions suggest a first course and the next one.
- **Check a certificate**: confirms any ZyeemZia certificate ID with the ZyeemZia server.

## Updating the course list

`data-academy.js` is generated from each course's own data. After a course changes, run from the tracks workspace:

```
node engine/academy_data.js
```

Then commit the new `data-academy.js` here.
